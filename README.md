# Task 6 – Sales Trend Analysis Using Aggregations

## Objective
Analyze monthly revenue and order volume using SQL aggregation functions.

## Analysis Performed

### 1. Monthly Revenue
Calculated total revenue for each month using SUM(amount).

### 2. Monthly Order Volume
Calculated the number of unique orders per month using COUNT(DISTINCT order_id).

### 3. Combined Monthly Analysis
Combined monthly revenue and order volume into one result table.

### 4. Top 3 Months by Sales
Identified the three months with the highest revenue.

### 5. Specific Time Period Analysis
Analyzed sales performance from July to December 2025.

### 6. NULL Value Analysis
Checked for NULL values in important columns.

### 7. Overall Sales Summary
Calculated:
- Total orders
- Total revenue
- Average order value
- Minimum order value
- Maximum order value

## Key Findings
- December 2025 had the highest monthly revenue.
- November 2025 had the second-highest revenue.
- October 2025 had the third-highest revenue.
- December revenue was 22,600.
- November revenue was 20,000.
- October revenue was 16,700.
- Each month contained 5 orders in the sample dataset.
- No NULL values were found in the main analysis columns.
